# volumeKeeper 仕様案（Windows 初期版）

状態: 初期版を実装済み（Windows 実機での音声切り替えは未検証）

## 目的

スピーカー、イヤホン、ヘッドセットなど、Windows の既定の音声出力先を切り替えたとき、機器ごとに保存した快適な音量へ自動的に戻す。

本仕様で扱う「音量」は、Windows が各出力先に持つマスター音量である。実際の音の大きさを測定・均一化する機能は対象に含めない。

## 対象

- OS: Windows 11。Windows 10 は初期版の対象外。
- 対象機器: Windows に音声出力先として表示される内蔵スピーカー、有線、USB、Bluetooth、HDMI など。
- 対象ユーザー: 1 台の PC で複数の音声出力先を使い分けるユーザー。
- 対象音量: 通常の再生用に設定された既定の出力先（Windows の `eMultimedia` ロール）のマスター音量。アプリ別音量、マイク入力音量、機器本体の独立した音量は対象外。

## 基本動作

1. アプリ起動時、既定の再生出力先と、その現在の音量を表示する。
2. ユーザーは出力先ごとに、次回の切り替え時に使う音量を設定できる。
3. 既定の再生出力先が変わったとき、切り替え先に保存済みの設定があれば、その出力先のマスター音量に適用する。
4. 保存済みの設定がない出力先では、現在の音量を維持し、設定可能であることを表示する。自動的に音量を上げない。
5. アプリの動作中、現在の既定出力先の音量がアプリ以外から変更されたら、その値を当該出力先の保存音量として自動保存する。未登録の出力先でも、この操作をきっかけに設定を作成する。
6. アプリ自身が保存音量を適用した結果として発生する変更通知は、自動保存の対象にしない。
7. 同じ出力先に対する重複通知や一時的な接続変動で、不要な音量の再設定を繰り返さない。
8. アプリを終了して再起動しても設定を保持する。ログイン時の自動起動はユーザーが選べる設定とする。

## 設定画面

- 現在の既定出力先、現在の音量、保存した音量、設定の有無を確認できる。
- 未登録の出力先では、現在の音量を変更せずにそのまま保存する操作もできる。
- 出力先ごとの保存音量を変更、削除できる。
- 現在の出力先の音量を 0.01% 刻みで指定して直ちに適用し、実際に反映された値を保存できる。
- 自動適用を一時停止、再開できる。
- 出力先を特定できなくなった古い設定を確認、削除できる。
- 音量変更に失敗した場合は、対象機器と理由を可能な範囲で表示する。

## 安全性と例外

- ミュート状態は自動解除しない。保存音量を適用する場合もミュート状態を維持する。
- 未登録の機器では音量を変更しない。
- 機器が切断された、既定の出力先が存在しない、音量を制御できない場合は再試行可能な状態として扱い、アプリが停止しないようにする。
- ユーザーが自動適用を一時停止している間は、音量を変更しない。
- 自動適用を一時停止している間も、ユーザーが変更した音量はその機器の設定へ自動保存する。
- アプリの起動時は現在の音量を優先し、保存音量を直ちに上書き適用しない。以後、既定の出力先が切り替わるときに保存音量を適用する。
- 別のアプリが現在の既定出力先のマスター音量を変更した場合も、アプリ自身による変更と区別できる範囲で自動保存の対象とする。

## 機器の識別

Windows の音声出力先を示す ID で設定を対応付ける。機器名だけでは同名機器を区別できないため、識別子には使わない。通常の出力先 ID はドライバー更新や機器の再インストールで変わり得る。Windows 11 バージョン 24H2 以降で安定した ID が取得できる場合はそれを使い、取得できない場合は通常の出力先 ID を使う。識別できなくなった場合は別の未登録機器として扱う。名前だけを根拠に古い設定を自動適用しない。

## 初期版の範囲外

- 再生音声の解析やラウドネス正規化
- アプリ別音量の調整
- マイク入力音量の管理
- 複数 PC 間の設定同期
- 音声出力先そのものの自動選択
- 通話用の既定出力先（`eCommunications` ロール）の監視と音量管理。開発が進んだ段階で検討する。

## 受け入れ条件

1. スピーカーに音量 A、イヤホンに音量 B を保存すると、既定の出力先を切り替えるたびに各保存音量が適用される。
2. 未登録の出力先へ切り替えても、アプリはその音量を変更しない。
3. 再起動後も保存設定が残り、アプリ起動中の出力先変更に反応する。
4. 自動適用を一時停止すると、出力先を切り替えてもアプリは音量を変更しない。
5. ミュート中に出力先を切り替えても、アプリはミュートを解除しない。
6. 保存済みの出力先で Windows の音量操作から音量を変更すると、新しい値が保存され、次回の切り替え時に適用される。
7. 未登録の出力先で Windows の音量操作から音量を変更すると、その値で設定が作成される。
8. アプリが保存音量を適用しても、その処理が新たなユーザー操作として記録されない。

## 初期版での音量適用

保存音量は一度に適用する。未登録の機器では音量を変更しない。保存音量に一律の上限は設けず、ユーザーが保存した値を使用する。段階的な変更や追加の音量上限は、実機での使用感を確認してから検討する。
